v1 API Docs EN中文

Public API for DaFreeAi Studio on Cloudflare Workers. Create an API key in the UI, then call /v1/* with Bearer auth.

Cloudflare Worker 上的公開 API。在 UI 建立 API Key 後，以 Bearer 呼叫 /v1/*。

Base: https://faa.kinai.workers.dev · Build: 2026-07-24-v6-account-pool

1. Create API Key / 建立 API Key

  1. Open Studio → Login and paste dafreeai localStorage JSON
  2. 開啟 Studio → 登入，貼上 dafreeai localStorage JSON
  3. Go to API tab → Create key
  4. 切到 API 分頁 → 建立 Key
  5. Plaintext faa_sk_... is shown once — copy immediately
  6. 明文 faa_sk_... 只顯示一次，請立即複製

2. Authentication / 認證

Authorization: Bearer faa_sk_...

Or / 或： X-Api-Key: faa_sk_...

Session UI routes use X-User-Id + X-User-Token instead.

Studio UI 的 session 路由改用 X-User-Id + X-User-Token。

3. Endpoints / 端點

  • GET /v1/models — model list / 模型列表
  • GET /v1/me — account / balance / key info · 帳號 / 餘額 / key 資訊
  • POST /v1/generate — submit generation (async) · 提交生成（非阻塞）
  • GET /v1/jobs/:jobId — poll result · 輪詢結果
  • GET /v1/history — history · 歷史

Pool management (session auth): GET/POST /api/pool, PATCH/DELETE /api/pool/:id, POST /api/pool/:id/release, GET /api/pool/stats

帳號池管理（session 認證）：同上路徑。

4. Generate example / 生成範例

export FAA_KEY=faa_sk_...
export BASE=https://faa.kinai.workers.dev

curl -s -X POST "$BASE/v1/generate" \
  -H "Authorization: Bearer $FAA_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt":"a cute cat",
    "model":"nano-banana-2-lite",
    "aspect":"1:1",
    "resolution":"1K",
    "quality":"low",
    "poolMode":"auto"
  }'

# Poll with returned chatId / jobId
curl -s -H "Authorization: Bearer $FAA_KEY" "$BASE/v1/jobs/"

5. Request fields / 請求欄位

  • prompt (required) — text prompt / 提示詞
  • model — default nano-banana-2-lite
  • aspect, resolution, quality, duration, audio
  • imagePaths / imageRefs — reference images (max 3)
  • fallback — auto | always | never (gpt-image smart fallback)
  • forceQuality — if true, do not auto-downgrade quality
  • poolMode — auto (default) | pool | personal

6. Recommended models / 建議模型

Default to nano-banana-2-lite (most reliable on unlimited package).

預設請用 nano-banana-2-lite（unlimited 最穩）。

gpt-image-2: prefer quality=low. Smart generate may retry low / fall back to lite when locked or not allowed. Alias gpt-image-2-fast is normalized to gpt-image-2.

gpt-image-2 建議 quality=low。smart generate 會在 locked / not allowed 時重試 low 或 fallback 到 lite。別名 gpt-image-2-fast 會正規化為 gpt-image-2。

7. Account pool (parallel generation) / 帳號池（並行生成）

Upstream dafreeai allows only one active generation per account. To support multi-user true parallelism, bind multiple credentials in the Pool tab. Each job acquires a free account, and the lock is released when the job completes or fails (TTL 5 minutes).

上游每個帳號同時只能跑一個生成。要支援多人真正並行，請在 帳號池 分頁綁多組憑證。每個 job 會占用一個空閒帳號，完成/失敗後釋放（鎖 TTL 5 分鐘）。

  • poolMode=auto — use pool if enabled accounts exist, else personal / 有池用池，否則個人
  • poolMode=pool — require free pool account; returns POOL_BUSY 503 if none / 強制池，無空閒回 503
  • poolMode=personal — always use caller credentials / 永遠用呼叫者憑證

Response may include fromPool, poolAccount, poolStats, adjustments.

回應可能含 fromPool、poolAccount、poolStats、adjustments。

True concurrency needs ≥2 free pool accounts.

真正並行需要池內至少 2 組空閒帳號。

8. Error codes / 錯誤碼

  • UNAUTHORIZED 401 — invalid key / Key 無效
  • FORBIDDEN 403 — revoked / insufficient scope · 已撤銷 / scope 不足
  • UPSTREAM_BUSY 409 — generation already in progress · 已有生成進行中
  • MODEL_NOT_ALLOWED 403 — unlimited package restriction · unlimited 限制
  • MODEL_LOCKED 503 — upstream model/account locked · 上游鎖定
  • PROMPT_LIMIT — duplicate/similar prompt rejected · 重複 prompt
  • POOL_BUSY 503 — no free pool account · 池內無空閒帳號
  • RATE_LIMITED 429 — 30/min general, generate 6/min · 一般 30/分、生成 6/分

9. Polling / 輪詢

Generate returns 202 with jobId/chatId and poll.url. Poll every ~3s until status is completed or error. Pool jobs resolve auth via internal jobmap so clients keep using the same API key.

生成回 202 與 jobId/chatId、poll.url。約每 3 秒輪詢直到 completed 或 error。池任務透過 jobmap 解析憑證，客戶端仍用同一 API Key 輪詢即可。
