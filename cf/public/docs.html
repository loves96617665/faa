v1 API 文件

Base: https://faa.kinai.workers.dev

1. 建立 API Key

  1. 開啟 Studio → 登入 貼上 dafreeai localStorage JSON
  2. 切到 API 分頁 → 建立 Key
  3. 明文 faa_sk_... 只顯示一次，請立即複製

2. 認證

Authorization: Bearer faa_sk_...

或 X-Api-Key: faa_sk_...

3. 端點

  • GET /v1/models — 模型列表
  • GET /v1/me — 帳號 / 餘額 / key 資訊
  • POST /v1/generate — 提交生成（非阻塞）
  • GET /v1/jobs/:jobId — 輪詢結果
  • GET /v1/history — 歷史

4. 生成範例

export FAA_KEY=faa_sk_...
export BASE=https://faa.kinai.workers.dev

curl -s -X POST "$BASE/v1/generate" \
  -H "Authorization: Bearer $FAA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"a cute cat","model":"nano-banana-2-lite","aspect":"1:1","resolution":"1K"}'

# 用回傳的 chatId / jobId 輪詢
curl -s -H "Authorization: Bearer $FAA_KEY" "$BASE/v1/jobs/"

5. 建議模型

預設請用 nano-banana-2-lite（unlimited 最穩）。

gpt-image-2 可能回 MODEL_NOT_ALLOWED_ON_UNLIMITED_PACKAGE 或 locked。

6. 錯誤碼

  • UNAUTHORIZED 401 — Key 無效
  • FORBIDDEN 403 — 已撤銷 / scope 不足
  • UPSTREAM_BUSY 409 — 已有生成進行中
  • MODEL_NOT_ALLOWED 403 — unlimited package 限制
  • MODEL_LOCKED 503 — 上游帳號池鎖定
  • RATE_LIMITED 429 — 30/min、generate 6/min
